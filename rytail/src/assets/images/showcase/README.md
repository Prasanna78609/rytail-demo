# Showcase Images

Place the 4 local showcase photos in this directory:

- `showcase-1.webp` (recommended 960x1200 or 4:5 portrait/vertical crop)
- `showcase-2.webp`
- `showcase-3.webp`
- `showcase-4.webp`

Once added, update the `image` field for each entry in `src/data/showcase.ts` (for example, importing them statically or referencing `/images/showcase/showcase-1.webp` if served from `public/`). Until these files are supplied, `ExpandingCard` renders gradient placeholders automatically.
